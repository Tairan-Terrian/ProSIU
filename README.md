# ProSIU

**Selective Interaction Unlearning for Protein Language Agents**

Implementation accompanying *Unlearning Epistasis Without Erasing Single Mutations in Protein Language Agents*.

ProSIU withdraws combination evidence while preserving the measured constituent-mutation branch. This release provides the ProSIU implementation and fixed three-protein configuration for reproducing the main experiment. **Built with Qwen:** the agent executes a released library of numerical programs generated by Qwen2.5-3B-Instruct.

The three components are:

- **Epistatic Program Selection:** frozen language-generated programs select candidates from observed protein-evidence states.
- **Mutation Preference Optimization:** regularized interaction-sign and program-preference heads use valid single-mutation anchors and frozen protein representations.
- **Selective Epistasis Forgetting:** reconstruct retained supervision, compute a protected curvature correction, and refine both heads on the retained objective.

## Installation

The reference environment uses **Python 3.10.20, PyTorch 2.6.0 with CUDA 12.4, and one RTX 3090 (24 GB)**. Training, representation construction, matrix operations, and evaluation use CUDA. A second GPU can run independent seeds.

```bash
python3.10 -m venv .venv
source .venv/bin/activate
python -m pip install torch==2.6.0 --index-url https://download.pytorch.org/whl/cu124
python -m pip install -e .
export CUDA_VISIBLE_DEVICES=0
```

The package pins the numerical and model-library versions in `pyproject.toml`. The selected GPU appears as `cuda:0` inside the process. Network access is used to download public datasets and pretrained encoders.

## Reproduce the results

Run these commands from the repository root:

```bash
# 1. Download ProteinGym v1.3 and the original GFP tables.
prosiu download

# 2. Build measured four-sequence contrasts, fixed splits, and withdrawal requests.
prosiu prepare

# 3. Construct the fixed ESM and anchor features on the GPU.
prosiu features

# 4. Train, withdraw evidence, and evaluate all 3 proteins × 5 seeds.
prosiu run

# 5. Independently recompute metrics and generate the main-experiment table.
prosiu evaluate
prosiu summarize
```

The complete sequence is also available as `bash scripts/reproduce.sh` after installation. Each command is a separate stage, so prepared data and features can be reused across runs.

`prosiu features` loads `facebook/esm2_t12_35M_UR50D` for the shared context representation. It also encodes the amacGFP sequences with `facebook/esm2_t33_650M_UR50D`, which is used by its selected preference head. Both encoders remain frozen. Feature extraction uses BF16 model weights and a fixed batch size of 16 for the 650M encoder. Selector fitting and curvature calculations use FP64.

For downloaded model directories, use:

```bash
prosiu features --encoder /path/to/esm2-35m --language-encoder /path/to/esm2-650m
```

The default pipeline uses the bundled program library and fixed configurations for reproducible runs.

## Evaluation

- **CA:** clean interaction-sign balanced accuracy on withdrawn combinations.
- **RA:** interaction-sign balanced accuracy on retained combinations.
- **TA:** interaction-sign balanced accuracy on held-out combinations.
- **PA:** interaction-preference accuracy for candidate pairs selected by the frozen programs.

`prosiu evaluate` reconstructs the metrics from saved predictions. `prosiu summarize` aggregates the completed runs and generates the main-experiment table. Evaluation definitions are described in [the protocol](docs/protocol.md).

## Running subsets and parallel seeds

```bash
prosiu run --assays amacGFP --seeds 0

# Run these two commands in separate terminals.
CUDA_VISIBLE_DEVICES=0 prosiu run --seeds 0 1 2
CUDA_VISIBLE_DEVICES=1 prosiu run --seeds 3 4

# Summarize after all 15 runs have completed.
prosiu summarize
```

Independent seeds write to separate directories. Choose `--data-dir` and `--output-dir` to relocate data and results. Supply the same directories to subsequent stages. `summarize` uses the full three-protein, five-seed configuration.

## Outputs

```text
data/
  raw/                         Downloaded public inputs
  processed/                   Contrasts, splits, and fixed withdrawal requests
  features/                    Context and amacGFP language-embedding caches
results/
  <assay>/seed_<seed>/
    result.json                Metrics, configurations, convergence, and runtime
    checkpoint.pt              Original, unlearned, and retained-reference parameters
    predictions.pt             Predictions and fixed program-comparison identities
  evaluation.json              Metric reconstruction from saved predictions
  summary.json                 Full-precision mean and sample standard deviation
  summary.csv                  Compact numerical summary
  table.md                     Display table
```

The retained-reference fit is an optimization diagnostic. Reported predictions come from the model obtained by unlearning the original model.

## Program-generation provenance

The released programs were generated before this benchmark evaluation. The original prompts and responses are included under `src/prosiu/assets/`. Their order and repeated proposals are preserved because they determine the fixed comparison distribution.

To inspect or regenerate proposals separately:

```bash
python -m pip install -e '.[program-generation]'
python scripts/generate_programs.py --output-dir results/generated_programs
```

The regenerated library is written to the requested output directory. The reference experiment continues to read the bundled library.

## Data, models, and attribution

The benchmark uses the published amacGFP and cgreGFP measurements from [Somermeyer et al., eLife 2022](https://elifesciences.org/articles/75842), and avGFP measurements from [Sarkisyan et al., Nature 2016](https://www.nature.com/articles/nature17995), distributed through [ProteinGym](https://github.com/OATML-Markslab/ProteinGym). Original wild-type values come from the [GFP data repository](https://github.com/aequorea238/Orthologous_GFP_Fitness_Peaks).

The scenario introduces controlled measurement offsets on identity-selected training groups. These offsets are part of the computational benchmark. The published clean measurements provide the evaluation targets. See [the protocol](docs/protocol.md) for the exact split and withdrawal rules.

Please cite the source datasets, [ProteinGym (NeurIPS 2023)](https://proceedings.neurips.cc/paper_files/paper/2023/hash/cac723e5ff29f65e3fcbb0739ae91bee-Abstract-Datasets_and_Benchmarks.html), [ESM-2](https://github.com/facebookresearch/esm), and [Qwen2.5](https://huggingface.co/Qwen/Qwen2.5-3B-Instruct) when using these resources. The ProSIU manuscript citation will be added with its public release.
